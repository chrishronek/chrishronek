### 🧑‍💻 About me

I help teams design, build, and run modern data platforms: orchestration, ELT, modeling, and the infrastructure underneath.

- 🚀 **Now:** building AI agents that streamline internal business operations
- ⭐ **Proudest project:** [**Cosmos**](https://github.com/astronomer/astronomer-cosmos) — run dbt Core projects natively as Apache Airflow DAGs
- 🏗️ **Also working on:** [SkaleData](https://skaledata.com) — Airflow, Airbyte, Superset & DataHub running in your own cloud account
- 💬 **Ask me about:** Airflow, dbt, Snowflake, data platform architecture, LLMs in production
- 🎲 **Motto:** *You live by the YOLO code deploy — you die by the YOLO code deploy.*
